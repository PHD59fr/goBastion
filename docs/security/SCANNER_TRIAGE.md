## Archive length and nonce bounds

The archive AEAD generates random nonces, with 28 bytes of overhead. Each archive
uses a fresh 256-bit data key and at most 2^20 segments. Canonical header JSON is
limited to 64 KiB. Chunk sizes are 1 through 2^20 bytes; frame lengths are checked
against that bound plus AEAD overhead before decoding. Manifest size/segment
multiplication is bounded by 2^40, and the zero-segment case avoids subtraction
underflow. These bounds explain selected G115 conversions; other conversion
findings require individual review.

restricted to the generic-api-key detector, an exact public fixture value, and

[.gitleaksignore](../../.gitleaksignore) contains one historical fingerprint for
a cryptokey test's PEM wrapper with a four-character dummy body. Its decoded
three bytes cannot encode an OpenSSH private key. The exception matches that
commit/path/detector/line only; it does not exclude other keys in the file.

```sh
gitleaks dir --config .gitleaks.toml --redact=100 --ignore-gitleaks-allow .
gitleaks git --log-opts="--all" --redact=100 --ignore-gitleaks-allow .
```

Keep reports redacted. To check exception boundaries, use disposable samples:
a fresh random key in an excepted filename and a fixture in an unlisted filename
must still be detected. A working-tree result does not cover Git history.

## Dependency constraints

The application does not import OpenPGP. The pinned x/crypto commit separates
the unused, unmaintained OpenPGP packages into a nested module; it does not make
those APIs safe. Keep them out of the application's graph. Dependency choices
are recorded in go.mod and go.sum; rerun govulncheck after dependency changes.
